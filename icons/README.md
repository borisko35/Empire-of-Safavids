# Что лежит в этой папке

Семь PNG, скачанных с Flaticon (имена `free-icon-*` — их выгрузка) плюс
один файл-превью. Ни один из них не читается кодом игры: пути иконок
предметов — это `icons/weapons/…` внутри `client/web/assets/`, а не эта
папка. Сюда смотрит только человек.

## Годных иконок — две, и они уже в деле

| Файл | Что | Где используется |
|---|---|---|
| `free-icon-interactivity-8467660.png` | рука нажимает на узел сети | `client/web/assets/deco/interactivity.png` — панель «Играть не скачивая» |
| `free-icon-rol-game-826214.png` | двое воинов с мечами | `client/web/assets/deco/role-play.png` — над сеткой классов |

Обе скопированы в сайт и покрашены в золото темы: файл — чёрный лайн-арт на
прозрачном фоне (alpha угла = 0), поэтому в CSS он подставлен маской, а не
тегом `<img>`, и цвет берётся из палитры сайта.

**Атрибуция обязательна.** Бесплатная лицензия Flaticon — та, что «Free
download — You must attribute the author». Автор обеих иконок — `Magnific`
(поле `authorName` на странице иконки), и требуемая строка со ссылками стоит
в футере `client/web/index.html` (класс `.footer-credits`). Удалять её
нельзя вместе с иконками.

## Остальные пять — не иконки

Это превью с уже вписанным текстом, в интерфейс они не годятся:

| Файл | Почему не годится |
|---|---|
| `6287184d70b56.png` | 3D-банк 2000×2000 с чужой подписью «3D RENDERING ICON» |
| `free-icon-computer-game-720718.png` | монитор со вписанным «START GAME» |
| `free-icon-level-up-7372119.png` | просто слово «LEVEL UP» чёрным по белому |
| `free-icon-computer-mouse-3355054.png` | зелёно-чёрная мышь: живая иконка, но палитра чужая сайту |
| `free-icon-save-856985.png` | флоппи с геймпадом, бирюза с жёлтым — тоже мимо палитры |

Первые три содержат чужой текст внутри картинки, последние две не спорят по
форме, но спорят по цвету: сайт тёмно-синий с золотом, а тут зелёный и
бирюзовый. Поэтому они остаются источником и в git не едут — правило в
`.gitignore` рядом.
