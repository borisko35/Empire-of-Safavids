# Разведка архитектурных ассетов: персидская / исламская архитектура

Дата: 24.10.2026. Задача: найти и скачать в `Assets/_staging/<имя>/source/` свободные (CC0 / CC-BY)
модели жилого персидского дома, караван-сарая / медресе / мечети с пиштаком, минарета, базарной аркады.

## 1. Итог

- **Скачано новых моделей: 0.** Причина инструментальная, а не содержательная: в этой сессии нет
  ни shell, ни HTTP-загрузчика бинарников. `fetch_content` возвращает только текст страницы и на
  бинарном файле падает (`fetch_content_invalid_response` — проверено на
  `https://threejs.org/examples/models/gltf/Duck/glTF-Binary/Duck.glb`), `write` пишет только UTF-8.
  Поэтому проверить сигнатуры (`glTF`, `Kaydara`) и размер > 10 КБ физически нечем: файлов нет.
- **Содержательный вывод: персидской жилой архитектуры (плоская крыша + бадгир + глухие стены +
  арочный вход) в свободных библиотеках нет.** Ближайшие находки — арабская и сахельская
  (Западная Африка) народная архитектура, и те выложены только как `.blend` / `.3ds`.
- **Побочная находка (важно для лицензий):** Quaternius с 28.08.2026 сменил лицензию с CC0 на
  собственный **Quaternius Asset License (QAL) v1.0**, который прямо запрещает перераспространение
  ассетов. Под правило «только CC0 / CC-BY» новые загрузки Quaternius больше не подходят.
  Уже лежащие в `Assets/_staging/quaternius` файлы скачаны раньше, когда действовал CC0.

## 4. Чего не нашлось (по пунктам задания)

1. **Персидский жилой дом (плоская крыша, купол, бадгир, глухие стены, арочный вход)** — 0 моделей.
   Бадгир/ветролов не встречается ни в одной свободной библиотеке из проверенных; на Sketchfab есть
   иранские модели, но без подтверждаемой CC0/CC-BY.
2. **Караван-сарай / медресе / мечеть с пиштаком и куполом** — 0. Есть только мечети других школ
   (Лаос, Таиланд) и уже лежащая в стейджинге `stone-mosque` (купол без пиштака).
3. **Минарет** — 0 свободных. Ближайшее по геометрии — `onion-dome-towers-asset-pack` (башни с
   луковичными куполами), но это не персидский минарет.
4. **Базарная аркада / лавка** — только универсальная арка (poly.pizza, CC-BY) и уже имеющиеся
   Quaternius `MarketStand_1/2`.

## 6. Рекомендация

Остаёмся на процедурной архитектуре: по типологии (бадгир, пиштак, караван-сарай) свободных моделей
нет, а то, что есть, — либо `.blend`, либо другая школа. Из свободного имеет смысл брать только
детали (арка, лавка, ковёр), и они уже в проекте. Если персидский дом нужен «как есть», реалистичный
путь — заказ или собственная процедурная сборка из модулей: глухая стена + плоская кровля + бадгир +
стрельчатый вход.

## 7. Как забрать, когда появится shell

Карточки (файлы отдаются по ссылкам внутри карточек, прямые URL не выдумываю):

- https://opengameart.org/content/lowpoly-desert-props — CC0, zip с FBX + glTF.
- https://poly.pizza/m/6LBYo9zP3wI — CC-BY, нужен `author` в THIRD_PARTY.md.
- https://poly.pizza/m/d6lqRR2TU0i — CC-BY, Poly by Google.

Проверка целостности после скачивания: у `.glb` первые 4 байта — `glTF`, у `.fbx` — `Kaydara`;
размер > 10 КБ; HTML-заглушки (начинаются с `<!DOCTYPE` / `<html`) удалять. Для poly.pizza прямая
ссылка на GLB лежит в HTML карточки в виде `https://static.poly.pizza/<uuid>.glb`
(так устроен `Assets/_staging/quaternius/pp-scan.py`).
