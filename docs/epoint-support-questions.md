ПОЧЕМУ ЭТОТ ВОПРОС ТАК ДЛИННЫЙ
------------------------------
Потому что в документе 52 страницы, и в нём есть опечатки. Две из них
проверяемы и уже нанесли бы ущерб:

  - домен epointv1.test в примере не существует (проверено запросом,
    отказ ENOTFOUND);
  - пример на странице 41 предлагает кодировать JSON через btoa без
    UTF-8. На русском или азербайджанском описании такой вызов в браузере
    выбрасывает исключение, а подпись считается по этой же строке — то есть
    запрос будет отвергнут как «неверная подпись», и виноватым окажется ключ.

Остальное проверяемо только на стенде.
